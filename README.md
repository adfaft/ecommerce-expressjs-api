# README

## Script
- all task : `npm run --list`
- start dev : `npm run dev`
- debug dev : `npm run debug-dev`, debug + dev

- build : `npm run build`
- test : `npm run test`, build + test
- test filter : `npm run test -- --filter="Test Post Crud"` , using test suite / describe info

- start prod : `npm run start`
  
- lint : `npm run lint`
- seed : `npm run seed`
- dbreset ; `npm run dbreset`


## TDD

- `xdescribe()` akan skip test suite
- `fdescribe()` akan fokus ke test suite
- `xit()` akan skip spec test
- `it()` jika tanpa function body, akan pending skip test test 
- `fit()` akan fokus ke  spec test
